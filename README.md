# Hari — Logistics & Shipping Student Portfolio

A responsive personal student portfolio website focused on logistics, shipping, supply chain management and international trade.

## Run locally
Open `index.html` in a web browser. No build command or environment variables are required.

## Before publishing
- Replace the photo placeholders with your own photo.
- Update `your.email@example.com` in `index.html` and `script.js`.
- Add your actual course, college, semester, projects, certificates, skills and social profile links.
- Replace sample academic project descriptions with your own work.

The contact form opens the visitor's email app using a `mailto:` link. It does not store form submissions. Google Fonts are loaded online; the site otherwise uses plain HTML, CSS and JavaScript.
